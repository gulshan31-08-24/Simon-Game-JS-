# 🎮 Simon Says Game

A colorful and interactive **Simon Says Game** built using **HTML**, **CSS**, and **JavaScript**. Test your memory by repeating the pattern the game shows. With each level, the sequence gets harder!

---

## 🧠 How to Play

1. Press **any key** to start the game.
2. Watch the colored buttons flash in a sequence.
3. **Repeat the sequence** by clicking the buttons in the same order.
4. With each level, the sequence gets longer.
5. The game ends when you click the wrong button.
6. Your **highest score** is tracked and shown at the top.

---

## 🚀 Features

- ✅ Colorful and smooth animations
- ✅ Sequence memory challenge
- ✅ Score and high score tracking
- ✅ “Game Over” effect with restart
- ✅ Easy to understand interface
